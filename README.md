# ⚙️ How to Run the Projects

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Siddhesh3804/Cohort-2.0_React.git
```

### 2️⃣ Navigate to the repository folder

```bash
cd Cohort-2.0_React
```

### 3️⃣ Open any task folder

Example:

```bash
cd "Task 1 - React"
```

### 4️⃣ Install dependencies

```bash
npm install
```

### 5️⃣ Run the development server

```bash
npm run dev
```
